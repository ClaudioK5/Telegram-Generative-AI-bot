# Telegram-Generative-AI-bot

This project is a fully automated pipeline running once everyday that uses a Generative AI model (DeepSeek) to **create daily content** and **automatically publish it to a Telegram channel** using a **Telegram bot.**

Ideal for daily tips, AI-powered insights, quotes, educational posts, and more.

**Currently in Use!**

This pipeline is **already running on the Telegram channel**:
